ChronoCode

El agente de IA de código abierto que corre en tu terminal

Diseñado para funcionar en cualquier sistema operativo (Android, Windows, macOS, Linux) sin necesidad de una PC potente.

Quick Start

      
Tres comandos y estás programando con IA. Elige tu sistema.


      

        

          
Termux (Android)

          
pkg update -y && pkg install -y python git
git clone https://github.com/jesusmoralesrodriguez925-spec/chronocode.git
cd chronocode
pip install requests python-dotenv
python chronocode.py

        


        

          
Windows

          
git clone https://github.com/jesusmoralesrodriguez925-spec/chronocode.git
cd chronocode
pip install requests python-dotenv
python chronocode.py

        


        

          
macOS / Linux

          
git clone https://github.com/jesusmoralesrodriguez925-spec/chronocode.git
cd chronocode
pip3 install requests python-dotenv
python3 chronocode.py

        

      

      
En Windows instala Python desde python.org marcando Add Python to PATH. Al primer inicio, ChronoCode te pide tu API Key.

¿Por qué BYOK?

      
Bring Your Own Key: tú pones la API Key, ChronoCode hace el resto.

      

        

          
[ ]

          
Sin servidores

          
No hay backend ni base de datos nuestra. ChronoCode habla directo con el proveedor que elijas.

        

        

          
[ ]

          
Privado

          
Tu clave vive solo en un archivo .env en tu equipo. Nosotros no recibimos tus claves ni tu código.

        

        

          
[ ]

          
Gratis

          
El agente es gratuito y de código abierto. Varios proveedores ofrecen capas gratuitas con límites de uso.
