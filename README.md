# ChronoCode · Landing Page

Landing page oficial de **ChronoCode**, el agente de IA de código abierto para la terminal.

## Qué contiene

- Presentación del proyecto y sus características.
- Guía de instalación rápida para Termux (Android), Windows, macOS y Linux, con botones para copiar cada comando.
- Lista de proveedores de IA soportados.
- Una simulación animada de la terminal que muestra cómo el agente crea y guarda un archivo.

## Tecnología

Está hecha con **HTML, CSS y JavaScript** puros, en un solo archivo (`index.html`), sin frameworks ni dependencias de compilación.

## Publicación

Se aloja con **GitHub Pages**. Para verla en local, abre `index.html` en tu navegador.

Los logos de los proveedores se cargan desde CDN, así que necesitas conexión a internet para verlos.
